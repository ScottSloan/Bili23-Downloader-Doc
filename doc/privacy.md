
# 隐私政策

Bili23 Downloader 是一款完全在本地运行的开源软件。**本程序没有自建账号系统，不收集、不上传任何个人信息**，也未集成广告或第三方数据分析组件。

本页面说明程序会在本机保存哪些数据、会向哪些服务器发起网络请求，以及你可以如何清除这些数据。

## 本地保存的数据

程序的全部用户数据均保存在本机的以下目录中，**不会上传至任何服务器**：

| 系统 | 数据目录 |
|---|---|
| Windows | `%APPDATA%\Bili23 Downloader\` |
| macOS | `~/Library/Application Support/Bili23 Downloader/` |
| Linux | `~/.local/share/Bili23 Downloader/` |

目录中各文件的用途如下：

| 文件 | 内容 |
|---|---|
| `config.json` | 程序设置，以及登录后的哔哩哔哩 Cookie |
| `task.db` | 下载任务列表与进度 |
| `history.db` | 下载历史记录，用于重复下载检测 |
| `thumbnail.db` | 视频封面的本地缓存 |
| `logs/` | 运行日志，用于排查故障 |

::: warning 关于登录凭据
使用扫码、短信验证或 Cookie 方式登录后，哔哩哔哩返回的 Cookie（`SESSDATA`、`bili_jct`、`DedeUserID` 等）会保存在 `config.json` 中，供后续请求使用。这些凭据**仅保存在你自己的电脑上**，程序不会将其发送给开发者或任何第三方。

该文件未经加密，因此请勿将 `config.json` 或整个数据目录分享给他人。如需清除，可在程序内退出登录。
:::

## 程序发起的网络请求

### 哔哩哔哩官方接口

解析链接、获取视频信息、下载媒体文件以及登录，均直接与哔哩哔哩的官方服务器通信，且全部由你的操作主动触发。这部分请求受哔哩哔哩自身的隐私政策约束。

程序仅在你自己账号已有的访问权限范围内操作，不会绕过任何付费墙、会员限制或技术保护措施。

### 版本更新检查

程序启动时会自动检查是否有新版本，你也可以在设置中手动检查。该请求发往 `https://verhub.hanloth.cn`，发送的内容仅包含：

- 当前程序的版本号
- 是否接收预览版的设置
- 操作系统类型（Windows / Linux / macOS）及其版本号

该请求**不包含任何个人身份信息、哔哩哔哩账号信息或设备唯一标识符**。服务端仅用这些信息判断是否需要更新，并统计各平台的版本分布情况。

除上述两类请求外，程序不会连接任何其他服务器，也不会发送遥测数据。

## 第三方组件

程序使用 FFmpeg 完成音视频合并与格式转换。FFmpeg 在本地执行，不会联网，也不会读取上述数据目录以外的内容。

## 清除数据

- **清除登录凭据**：在程序内退出登录即可。
- **清除全部数据**：卸载程序后，手动删除上表中对应的数据目录。

## 政策变更

本隐私政策如有修改，将直接更新于本页面，并在程序的发布说明中注明。
