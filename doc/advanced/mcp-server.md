# MCP 服务器

程序内置了一个 MCP（Model Context Protocol）服务器，开启后，支持该协议的 AI 客户端（如 Claude Code、Claude Desktop、Cherry Studio 等）就能直接控制下载器：解析链接、创建下载任务、查询进度、暂停或取消任务。

你可以直接对 AI 说「把这个链接的视频全部下载下来」，它会自行完成解析与建立任务的全过程。

::: warning ⚠️ 该功能默认关闭
开启后程序会在本机监听一个端口。请先阅读下方的 [安全说明](#安全说明)，确认你了解它的作用后再启用。
:::

## 开启方式

在 **[设置页] → [高级] → [MCP 服务器]** 中打开「启用 MCP 服务器」。

| 选项 | 说明 |
| :--- | :--- |
| 启用 MCP 服务器 | 总开关，默认关闭 |
| 状态 | 显示当前监听地址，或启动失败的原因 |
| 端口 | 默认 23330。被其他程序占用时可以改为其他值 |
| 允许下载操作 | 关闭后 AI 只能查看，不能创建、暂停或取消任务 |
| 访问令牌 | 每次请求都必须携带，相当于密码 |
| 客户端配置 | 一键复制可直接使用的客户端配置 |

修改开关、端口或令牌后服务器会自动重启，无需重启程序。

## 配置 AI 客户端

点击「客户端配置」右侧的**复制**按钮，得到一段这样的配置：

```json
{
  "mcpServers": {
    "bili23-downloader": {
      "type": "http",
      "url": "http://127.0.0.1:23330/mcp",
      "headers": {
        "Authorization": "Bearer 你的访问令牌"
      }
    }
  }
}
```

把它粘贴进 AI 客户端的 MCP 配置文件即可。各家客户端的配置文件位置不同，请参考对应客户端的说明。

如果使用 Claude Code，也可以直接用命令行添加：

```bash
claude mcp add --transport http --scope user bili23 http://127.0.0.1:23330/mcp --header "Authorization: Bearer 你的访问令牌"
```

::: tip 💡 关于 `--scope user`
不加这个参数时，配置只会写入当前项目的局部配置，部分运行环境不会加载它，表现为「连接显示正常，但一个工具都没有」。加上 `--scope user` 写入全局配置可以避免这个问题。
:::

配置完成后需要**重新启动 AI 客户端**（或新开一个会话），它才会读取到新增的服务器。

## 可用功能

| 功能 | 说明 |
| :--- | :--- |
| 解析链接 | 解析 B 站链接，结果会显示在程序的解析界面上 |
| 查看剧集 | 列出当前解析结果中的条目 |
| 创建下载 | 按条目建立下载任务 |
| 任务列表 | 查看下载中或已完成的任务 |
| 任务状态 | 查看单个任务的进度、速度与文件路径 |
| 暂停 / 继续 / 取消 | 控制下载中的任务 |
| 登录状态 | 查询当前账号，用于判断能否下载会员内容 |

出于安全考虑，AI **不能**修改程序设置，画质、命名规则等配置只能由你在界面上更改。AI 创建的下载任务会沿用你当前的所有设置。

## 安全说明

- **只监听本机**：服务器绑定在环回地址 `127.0.0.1` 上，同一局域网内的其他设备也无法访问。
- **必须携带令牌**：每个请求都要带上访问令牌，令牌不正确的请求会被直接拒绝。
- **令牌请勿外传**：它等同于操作你下载器的密码。若不慎泄露，点击「重新生成」即可作废旧令牌，之后需要用新令牌重新配置 AI 客户端。
- **可限制为只读**：关闭「允许下载操作」后，AI 只能查询状态，无法创建或删除任何任务。

## 注意事项

::: warning ⚠️ 程序必须处于运行状态
AI 客户端是在启动时连接服务器的。如果启动时 Bili23 Downloader 没有运行，该次会话将无法使用这些功能，需要先打开程序再重新启动客户端。
:::

- **解析会替换当前列表**：AI 发起解析时，程序解析界面上原有的内容会被替换。为避免打断你的操作，当界面上有你手动勾选的条目时，AI 的解析请求会被拒绝，此时需要你先完成或清空当前的选择。
- **下载目录与命名**：AI 创建的任务与你在界面上点击下载完全一致，遵循相同的下载目录、命名规则与画质设置。
- **端口被占用**：若状态栏提示启动失败，多为端口被其他程序占用，改用其他端口即可。

## 常见问题

**AI 客户端里找不到相关功能？**

依次检查：程序是否正在运行、MCP 服务器开关是否已打开、配置中的令牌是否与程序内一致、添加配置后是否重新启动了 AI 客户端。使用 Claude Code 时还需确认是否加了 `--scope user`。

**提示需要登录或画质不足？**

MCP 使用的是你当前登录的账号。会员内容与最高画质需要相应的账号权限，可在程序内登录后重试。

**AI 说找不到某个任务？**

暂停、继续、取消只能作用于下载队列中的任务。已经下载完成的任务不能再被这些操作控制。
